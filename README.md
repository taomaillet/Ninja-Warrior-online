# Ninja Warrior Online
Windows : extraire le ZIP, arrêter tout autre serveur sur le port 3000, puis double-cliquer sur LANCER.bat. Actualiser le navigateur si le serveur démarre après son ouverture.
En ligne : déposer le contenu du dossier sur GitHub, puis créer un Blueprint Render depuis ce dépôt (render.yaml fourni). Ou Web Service Node, npm install, npm start. Partager l'URL Render et le code du salon.
50 participants au départ, bots utilisant les mêmes collisions que les humains, quatre manches. Flèches ou Q/D, espace, Maj, E pour la corde. Salons en mémoire, perdus au redémarrage. Version prototype 2D, pas de compte ni de sauvegarde.
